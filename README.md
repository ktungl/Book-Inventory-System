Book Inventory Management System
A comprehensive desktop application built with WinForms, designed specifically for independent bookstores that need efficient inventory management without the complexity of an online storefront.
Features

Staff Management: Manage administrators and staff accounts with role-based access
Customer Management: Maintain customer records and purchase history
Inventory Control: Track book stock, pricing, and catalog information
Order Processing: Handle sales transactions and order fulfillment
All-in-one Solution: Centralized management system for daily bookstore operations
